## Entorno de Base de Datos
- La usuaria tiene **MySQL** y **SQL Server 2025** instalados en su máquina de desarrollo.
- El proyecto `menu-compras` usa **MySQL** con la librería `mysql2`.
- Para proyectos con SQL Server, la autenticación puede estar configurada en **Windows Authentication** por defecto. Verificar si Mixed Mode está habilitado antes de configurar conexiones con usuario/contraseña.
